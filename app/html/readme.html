Memris Protocol

The market remembers the price. Memris remembers who moved first.

Memris is a market-memory agent built for Robinhood Chain and represented by a small cat living inside this desktop.

Memory rules

01 / FINITE
Only thirty-two memories may remain active at once.
02 / WITNESSED
Every memory is timestamped before its outcome is known.
03 / MORTAL
At midnight the current Memris ends. Four memories survive into the next life.
04 / HONEST
A wrong call becomes a scar. It is never polished into a prediction she did not make.
